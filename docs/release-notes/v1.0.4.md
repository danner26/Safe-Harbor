# v1.0.4 — UI polish, optional email, and timeline timezone fix

## Mobile and UI polish

- The mobile header brand/logo is now a tappable link back to the home page.
- Status badges no longer wrap onto a second line.
- The tank-detail header no longer overflows on narrow / mobile viewports.
- Wide data tables now scroll horizontally instead of overflowing the page.
- New mobile "More" hub: Livestock, Measurements, Settings, and Reports are reachable from the bottom tab bar's "More" tab. Livestock is now reachable on mobile.
- Improved contrast of the modal close button in dark mode.

## Email is now optional

- `SMTP_HOST` is no longer required in production. Deployments without an SMTP provider now start cleanly; a warning is logged and password resets remain available through the admin UI (an admin issues a one-time reset URL to share out-of-band).
- `/healthz` now reports `"email": "configured"` or `"email": "disabled"` so operators can verify email status at a glance.
- `install.md` and `config.md` updated to document the admin-mediated password-reset flow and the optional SMTP contract.

## Startup diagnostics

- The container entrypoint now surfaces the actual error output from its migration-state checks on failure, instead of swallowing it and silently restarting. Early-startup misconfiguration (database auth, missing environment variables, import errors) is far easier to diagnose from `docker logs`.

## Animal timeline timezone fix

- Animal lifecycle events are now displayed in the timezone of the tank the animal occupied at the time of the event. Previously, events without a directly-associated tank were rendered in the animal's *current* tank timezone, which could show the wrong local time after an animal was moved between tanks in different timezones.

## CI / release pipeline

- GitHub Actions updated to current major versions across the build and release workflows; Dependabot now targets the integration branch.

## Schema changes

This release adds one migration: a new nullable `tank_id_at_event` column on animal events, backfilled automatically from existing tank history. Run `flask db upgrade` after updating — the backfill is automatic and requires no operator action.
